# protondrive: An Interface to Proton Drive

Manage files on Proton Drive from R. Functions mirror the 'googledrive'
package: list, find, upload, download, copy, move, rename, trash, and
share files and folders. All end-to-end encryption, session handling,
and API traffic are delegated to the official Proton Drive command-line
interface, which is built on the Proton Drive SDK
<https://github.com/ProtonDriveApps/sdk>. This is a third-party package
that is not officially supported by Proton.
